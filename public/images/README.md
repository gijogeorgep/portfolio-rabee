# Rabee Portfolio — Image Directory Structure

You can replace any image in your portfolio simply by replacing the corresponding file below with your own image (keep the same filename, or update the path in `src/data.js`).

## 1. Hero Section (`public/images/hero/`)
* `hero.jpeg` — Main full-screen background image in the Hero section.
* `poster.jpeg` — Video poster fallback image.

## 2. About Section (`public/images/about/`)
* `portrait.jpg` — Main portrait photo of Rabee (with scroll parallax).
* `rig-onset.jpg` — Secondary on-set 35mm camera rig photo.
* `optics.jpg` — "Optics & Glass" process photo.
* `scouting.jpg` — "Location Scouting" process photo.
* `slate.jpg` — "Production Slate" process photo.

## 3. Projects (`public/images/projects/`)
* `nordlys-cover.jpg` + `nordlys-1.jpg`, `nordlys-2.jpg`, `nordlys-3.jpg`
* `saltwater-cover.jpg` + `saltwater-1.jpg`, `saltwater-2.jpg`, `saltwater-3.jpg`
* `concrete-bloom-cover.jpg` + `concrete-bloom-1.jpg`, `concrete-bloom-2.jpg`, `concrete-bloom-3.jpg`
* `after-hours-cover.jpg` + `after-hours-1.jpeg`, `after-hours-2.jpg`, `after-hours-3.jpg`

## 4. Film Posters (`public/images/films/`)
* `echoes-of-ember.jpg` — Short Film poster.
* `velocity.jpg` — Commercial film poster.
* `the-long-way-home.jpg` — Documentary film poster.

## 5. Horizontal Gallery (`public/images/gallery/`)
* `gallery-01.jpg` through `gallery-10.jpg` — The 10 photographs featured in the smooth horizontal scroll gallery.

> **Tip**: All paths are centrally linked in [src/data.js](../../src/data.js). If you add new images or change filenames, simply update `src/data.js`.
