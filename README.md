# RABEE Portfolio
Cinematography & Photography Portfolio for Rabee.

```bash
npm install
npm run dev
```

## Replacing Images
All images are organized by section in [public/images/](file:///d:/rabee%20portfolio/lumen/public/images/):
- **Hero**: `public/images/hero/hero.jpeg`
- **About**: `public/images/about/` (`portrait.jpg`, `rig-onset.jpg`, `optics.jpg`, `scouting.jpg`, `slate.jpg`)
- **Projects**: `public/images/projects/` (`nordlys-*.jpg`, `saltwater-*.jpg`, `concrete-bloom-*.jpg`, `after-hours-*.jpg`)
- **Films**: `public/images/films/` (`echoes-of-ember.jpg`, `velocity.jpg`, `the-long-way-home.jpg`)
- **Gallery**: `public/images/gallery/` (`gallery-01.jpg` to `gallery-10.jpg`)

Simply drop your new images into these folders, or change image paths & descriptions in [src/data.js](file:///d:/rabee%20portfolio/lumen/src/data.js).
